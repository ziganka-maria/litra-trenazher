# README — техническая документация

## «ЛитРа Тренажёр»

Полное описание устройства приложения, чтобы его можно было понять, доработать и «собрать» заново.

---

## 1. Что это

Одностраничное офлайн-приложение в одном файле `index.html`. Никаких внешних файлов, библиотек и сборки нет: всё (HTML, CSS, JS, данные, SVG-картинки) находится внутри.

«Собрать» приложение = просто открыть `index.html` в браузере. Отдельного шага сборки не существует.

## 3. Структура файла `index.html`

Внутри `index.html` три смысловые части:

1. **`<style>`** — стили (CSS).
2. **`<body>`** — разметка экранов: стартовое меню, игровой экран, экран результата.
3. **`<script>`** — данные и логика (см. ниже).

---

## 4. Данные (главные объекты JS)

### 4.1. `CATEGORIES` — разделы викторины
Массив из 4 разделов:
```js
{ id: 'pushkin', emoji: '🎩', title: '…', desc: '…' }
{ id: 'class',    emoji: '📖', … }
{ id: 'vneklass', emoji: '🌍', … }
{ id: 'mixed',    emoji: '🎲', … }  // «всё вперемешку» — не фильтрует
```

### 4.2. `QUESTIONS` — произведения викторины (237 шт.)
Каждый объект:
```js
{
  cat: 'pushkin',            // 'pushkin' | 'class' | 'vneklass'
  gr: 3,                     // класс (1–4) или null
  ans: ['сказка о царе салтане', 'царь салтан'], // правильные варианты (нестрогая проверка)
  em: '👑 🌊 🦢',            // эмодзи-подсказка
  pic: 'saltan',             // ключ картинки из pictures (или поле отсутствует)
  au: 'А. С. Пушкин',        // подсказка «кто написал» (или отсутствует)
  ln: '«Ветер по морю гуляет…»', // подсказка «строчка» (или отсутствует)
  fact: '33 богатыря …'      // пояснение после ответа
}
```

### 4.3. `pictures` — SVG-картинки
Объект-словарь: ключ → строка SVG. Доступные ключи:
`saltan`, `fish`, `rooster`, `mirror`, `church`, `oak`, `horse`, `turnip`, `bear`.

### 4.4. `TEXT_A` … `TEXT_H`
8 текстов, используемых в тренажёре «Вариант ВПР» (каждый вариант = художественный + научно-популярный текст).

### 4.5. `VPR` — тренажёры подготовки к ВПР (9 шт.)
Каждый тренажёр:
```js
{
  id: 'genre',            // уникальный id
  icon: '🏷️',
  title: 'Жанры',
  desc: '…',
  shuffle: false,         // необязательно: не перемешивать порядок вопросов
  block: true,            // необязательно: вопросы группируются по тексту
  questions: [ … ]
}
```

Типы вопросов внутри `questions`:

**Обычный вопрос (выбор из 4 вариантов):**
```js
{ q:'Вопрос?', opts:['Верный','Неверный 1','Неверный 2','Неверный 3'], ans:0, why:'Пояснение.' }
```
`ans` — индекс правильного ответа в `opts`. В данных он обычно `0` (правильный первым), но при показе варианты перемешиваются автоматически.

**Раунд «Собери пословицу» (только в тренажёре `match`):**
```js
{ type:'match', pairs:[ {a:'Начало', b:'окончание'}, … ] }
```

**Вопрос к тексту (тренажёры `text` и `variant`):**
```js
{ p:TEXT_A, q:'Вопрос по тексту?', opts:[…], ans:0, why:'…' }
```
Все вопросы с одинаковым `p` автоматически группируются в один блок: текст показывается сверху один раз, под ним — список вопросов.

## 5. Логика (основные функции)

- `shuffle(arr)` — перемешивание массива (не изменяет исходный).
- `norm(s)` — нормализация строки (нижний регистр, ё→е, убрать знаки).
- `stripGenre(s)` — убрать слово «сказка/стихотворение/…» в начале.
- `levenshtein(a,b)` — расстояние Левенштейна (для прощения опечаток).
- `isMatch(input, variants)` — проверка текстового ответа.
- `renderCategories()` / `renderVprMenu()` — построение меню.
- `startGame(cat)` — запуск викторины.
- `startVpr(trainer)` / `groupBlocks(list)` — запуск тренажёра ВПР.
- `renderQuestion()` — отрисовка текущего задания (ветки: викторина / вопрос / match / блок текста).
- `buildHints()` / `revealHint()` — подсказки.
- `buildOptions()` / `chooseOption()` — варианты ответа (перемешиваются).
- `renderBlock()` / `chooseBlockOption()` — текстовые блоки.
- `renderMatch()` / `selectLeft()` / `selectRight()` / `finishMatch()` — «Собери пословицу».
- `checkAnswer()` / `giveUp()` — ввод названия и «сдаюсь».
- `next()` / `showResults()` / `computeMax()` — переходы и итог.
- `toggleOpts` — кнопка «Скрыть/показать варианты».

---

## 6. Система очков

**Викторина:** старт 30 очков; −10 за каждую подсказку, −5 за каждую ошибку; минимум 5. «Сдаюсь» = 0.

**Тренажёры ВПР:** +10 за верный ответ (вопрос или подвопрос в текстовом блоке).
**Собери пословицу:** 10 очков за раунд минус 1 за каждую ошибку.

## 7. Как добавить новый контент

### 7.1. Добавить произведение в викторину
Вставить объект в массив `QUESTIONS` (см. формат 4.2). Пример:
```js
{ cat:'class', gr:2, ans:['название','короткий вариант'], em:'📖', pic:null, au:'Автор', ln:'«Цитата…»', fact:'Факт.' },
```

### 7.2. Добавить вопрос в тренажёр ВПР
Вставить в `questions` нужного тренажёра:
```js
{ q:'Вопрос?', opts:['Верный','Неверный','Неверный','Неверный'], ans:0, why:'Пояснение.' },
```

### 7.3. Добавить раунд в «Собери пословицу»
```js
{ type:'match', pairs:[{a:'Без труда', b:'не вытащишь и рыбку из пруда'}, …] },
```

### 7.4. Добавить текст в «Работа с текстом» / «Вариант ВПР»
Добавить вопросы с одинаковым `p` (для варианта — завести константу `TEXT_I` и ссылаться `p:TEXT_I`). Вопросы сгруппируются в один блок автоматически.

### 7.5. Добавить картинку-подсказку
Добавить ключ в объект `pictures` и указать его в поле `pic` у произведения.

## 8. Пересборка / публикация

- Сборка **не нужна**: файл самодостаточен.
- Для локального запуска — открыть `index.html`.
- Для публикации — загрузить один файл `index.html` на любой статический хостинг (GitHub Pages, Netlify и т.п.).

## 9. Проверка

Работоспособность проверяется открытием в браузере. Для автоматической проверки синтаксиса JS можно выполнить в терминале:
```powershell
$html = Get-Content -Raw 'index.html'
$m = [regex]::Match($html, '(?s)<script>(.*?)</script>')
Set-Content '_check.js' -Value $m.Groups[1].Value -Encoding UTF8
node --check '_check.js'
```
