КАК ОТКРЫТЬ ПРИЛОЖЕНИЕ «ЛИТРА ТРЕНАЖЁР»
==========================================

Файл приложения: index.html
Это обычная веб-страница, она открывается в любом современном браузере.
Интернет и установка НЕ нужны.

────────────────────────────────────────
▶ НА КОМПЬЮТЕРЕ (Windows)
────────────────────────────────────────
1. Скачайте архив ЛитРа_Тренажер.zip и распакуйте его
   (правый клик → «Извлечь всё»).
2. Дважды кликните по файлу index.html.

Если вместо игры открылся «Блокнот» или Internet Explorer:
   - кликните ПРАВОЙ кнопкой по index.html
   - выберите «Открыть с помощью» → Google Chrome / Edge / Firefox
   - поставьте галочку «Всегда использовать это приложение»
   - нажмите ОК.

────────────────────────────────────────
▶ НА КОМПЬЮТЕРЕ (Mac)
────────────────────────────────────────
Дважды кликните по index.html — откроется в Safari или Chrome.

────────────────────────────────────────
▶ НА ТЕЛЕФОНЕ / ПЛАНШЕТЕ (Android)
────────────────────────────────────────
1. Скачайте архив и распакуйте его.
2. Откройте «Мои файлы» (файловый менеджер), найдите index.html.
3. Нажмите на файл → выберите «Открыть в браузере» (Chrome).

Если не открывается — установите бесплатное приложение
«HTML Viewer» из Google Play и откройте файл через него.

────────────────────────────────────────
▶ НА iPhone / iPad
────────────────────────────────────────
Напрямую HTML-файлы открываются неудобно.
Лучше всего открыть приложение ПО ССЫЛКЕ (см. ниже).

────────────────────────────────────────
▶ САМЫЙ НАДЁЖНЫЙ СПОСОБ — ОТКРЫТЬ ПО ССЫЛКЕ (работает у ВСЕХ)
────────────────────────────────────────
Загрузите index.html на бесплатный хостинг и отправьте подруге ссылку.
Тогда приложение откроется на любом телефоне и компьютере:

• Netlify Drop (проще всего):
   1. Откройте в браузере адрес:  https://app.netlify.com/drop
   2. Перетащите туда папку с файлами проекта.
   3. Через пару секунд появится ссылка — отправьте её подруге.

• GitHub Pages:
   1. Зайдите на github.com, создайте новый репозиторий.
   2. Загрузите в него index.html.
   3. Settings → Pages → выберите ветку → получите ссылку.

────────────────────────────────────────
▶ ВАЖНЫЕ СОВЕТЫ
────────────────────────────────────────
• Пересылайте только АРХИВ (.zip), а не голый файл .html:
  некоторые мессенджеры (WhatsApp, Telegram) могут испортить
  или заблокировать html-файл.
• Если страница открылась, но экран БЕЛЫЙ (пустой) — значит,
  браузер устарел. Обновите Chrome или Edge до последней версии.
• Файл самодостаточный: интернет для работы не нужен.
